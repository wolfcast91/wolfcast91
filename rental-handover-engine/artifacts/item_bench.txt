WHY - the ambiguous ones in the author's own words
--------------------------------------------------
  projector
      AMBIGUOUS: sits under an optics root, but a sealed LED projector is robust, so it stays Tier 1 where a DSLR does not.
  chainsaw
      AMBIGUOUS: dangerous, but danger is not a handover attribute. No licence is required in DE for private use, so it automates.
  camping_gear
      AMBIGUOUS: many detachable parts, but R06 deliberately excludes low-value kits, so a tent bag does not force a meetup.
  kayak
      AMBIGUOUS: not fragile, not licensed, not valuable enough for Tier 3 - it is simply too big for a box.
  scaffolding
      AMBIGUOUS: six detachable parts would suggest Tier 3, but a parts count verified in a marked bay is a Tier 2 checklist.
  party_tent
      AMBIGUOUS: same reasoning as scaffolding - fixed location beats parts count.
  sewing_machine
      AMBIGUOUS: boxable and hand-carried, so it looks like Tier 1 - fragility is the only thing that moves it, and it graduates once proven.
  ebike
      AMBIGUOUS: robust and unboxable, which would say Tier 2, but high value plus detachable parts outranks that at precedence 50.
  trailer
      AMBIGUOUS: machine-lift would say Tier 2, but a road-legal trailer with straps and a spare is a value-plus-parts case.
  laser_level
      AMBIGUOUS: a boxable hand tool, but a knocked rotary laser is a calibration bill, so fragility wins.
  mini_excavator
      AMBIGUOUS: small enough that people assume it automates. Instruction and inspection duties are regulatory, so it cannot.
  carpet_cleaner_depot
      AMBIGUOUS: identical machine, different custody. Consigning it to a partner node changes the tier - which is the point of grouping by mechanism, not item type.
