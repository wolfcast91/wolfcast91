# content/

Alles Nicht-Footage-Material der Content-Serie **„Weg zum Porsche"** (Auto kaufen → reparieren →
verkaufen als Weg zum Traumauto). Deutsch, vertikal 9:16, YouTube / Instagram / TikTok.

Rohes Videomaterial gehört **nicht** hier rein – das liegt extern unter
`/Volumes/holdmydata/camera/` und ist in `.gitignore` ausgeschlossen.

## Struktur

| Pfad | Inhalt |
|---|---|
| `HANDOVER.md` | Projekt-Kontext, Season-Setup, Anonymitätsregel, Tools. **Bei Wiederaufnahme zuerst lesen.** |
| `CATALOG_PROMPT.md` | Arbeitsanweisung für die Footage-Katalogisierung inkl. Sampling-Policy nach Clip-Länge |
| `season-1/ROHKATALOG.md` | Gemergter Gesamtkatalog Season 1 (nach Kategorien + `NEEDS BLUR`-Checkliste) |
| `season-1/catalog/` | Zwischenergebnisse pro Footage-Unterordner (`catalog_folder1.md` …) |

Später hier: Skripte, Shootinglisten, Postpläne, Poll-/Cliffhanger-Texte, Giveaway-Mechanik (Season 2).

## Verwandt

- `../cooper-animations/` – Remotion-Projekt für die Intro-/Hook-Animationen (Export → MP4 →
  Overlay in CapCut / iMovie).
